# ADVISOR front page

A static field map: plain HTML, CSS and a little vanilla JS, no build step. Serve `site/` from anywhere
(`php -S localhost:8000 -t site`, Citadel, any static host) and open `index.html`.

type: **Fraunces** (SIL OFL 1.1, self-hosted in `assets/fonts/`, licence in `OFL-fraunces.txt`) for display and map
lettering; Lato from WayneUI for body; WayneUI's mono stack for code.

- **World:** an orienteering sheet on cream paper. Contours in green ink, the course overprinted in the board's maroon
  `#8B2145`, gold `#FFCC33` for "you are here" and lit waypoints, green `#0C5449` as the family tie.
- **Magic:** "Ask the map". A question plots a route from your app, through ADVISOR, past the real tool that answers
  (`policy_lookup`, `run_proctor_check`, `read_project_docs`, ...) to the stack project the answer comes from. Waypoints
  light as the pencil reaches them, and the route card writes the whole answer out in text. Version answers are worked
  out live from the bundled CREED policy dates, the same way `PolicyReader` does.
- **WayneUI 2.0.8** is copied into `assets/wayne-ui/` (tokens, Lato, container, buttons, skip link). Marks of the other
  parts are in `assets/marks/` (WayneUI's own mark, never the WSU shield). ADVISOR's mark and favicons are in `brand/`.
- **Terrain:** `assets/terrain-*.svg` are generated by `node site/tools/contours.mjs` (fixed seed). The page never runs it.
- **Reduced motion:** the finished map, every route drawn, every word present at first paint.

Screenshots are in `screenshots/` (desktop, mobile, reduced motion, a motion GIF, and mobile crops per section).
