# ADVISOR

ADVISOR is the stack's MCP server, like Laravel Boost for WSU: it orients a developer and gives their agent tools into every stack project. It is part of WELD, the Wayne State application stack, beside WayneUI, CREED, PROCTOR, PREFLIGHT, SESAME, HELMET, Pinstripe and Sourdough.

> Every WSU student has an advisor. Now every WSU app does too, and this one answers email.

Status: scaffolding. The 0.1 build is under way.
